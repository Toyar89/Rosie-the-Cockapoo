Rosie Call Page with Ringtone Test

Upload these files to your GitHub Pages repository:
- index.html
- style.css
- script.js
- rosie-photo.png
- rosie-message.mp4
- ringtone-ios.mp3

VERY IMPORTANT:
The ringtone must be named exactly:
ringtone-ios.mp3

GitHub is case-sensitive, so these are NOT the same:
ringtone-ios.mp3
Ringtone-ios.mp3
ringtone-IOS.mp3
ringtone-ios.MP3

How to test:
1. Upload all files.
2. Open the page on your phone.
3. Tap Test Ringtone.
4. If the page says "Ringtone not found", the filename or location is wrong.
5. If the page says "Ringtone playing" but you hear nothing, check phone volume/silent mode.
6. Tap Start Incoming Call.

Important:
Your ringtone file must be called exactly:
ringtone-ios.mp3

Why there is a Start Incoming Call button:
Mobile browsers usually block sound from autoplaying when a page first loads.
The start button gives the browser the user tap it needs, so the ringtone can play properly.

Features:
- Desktop users see the smartphone-only warning.
- Portrait phone users see the Rosie call experience.
- Landscape phone users see a rotate-phone warning.
- Ringtone plays after Start Incoming Call is tapped.
- Ringtone stops when Answer or Decline is tapped.
- Video plays after Answer.
- End Call button works over the video.
- Answer and Decline buttons are restored as round phone-style buttons.
- Personalised name links work:
  index.html?name=Sarah
